NVFlare · Confidential workload deployment

Four parties. One gated release.

A Mermaid sequence of platform approval, encrypted workload publication, and live CPU + GPU attestation. The CoCo operator controls the host; only an approved confidential guest can decrypt the workload.

AMD SEV-SNP + NVIDIA confidential GPUKata 3.29.0 · digest-pinnedIndependent key-release authority

Trusted platform system

Rehearses approved launch conditions and verifies hardware-signed reference evidence.

NVFlare provisioning node

Coordinates handoffs; builds, encrypts and signs the workload; generates its Pod and policies.

Secure services

TLS registry, Trustee/KBS, AS and RVPS appraise evidence and authorize each resource release.

CoCo IT + cluster

Untrusted host administration. The protected guest inside the cluster is a separate security boundary.
