# coco: public package baseline

This file describes packaged capabilities, not the state of any live machine.
Start with [../CONFIGURATION.md](../CONFIGURATION.md) and [README.md](README.md).
No running Pod, issued certificate, installed policy, or measurement is implied
by the presence of these files. Obtain fresh deployment inputs and record local
execution results privately.

Public software pins are in the role's example configuration or public runtime
pins. Kubernetes/containerd/Kata bootstrap code is included where needed.
Workload and platform approval values are generated through the trusted workflow,
not copied from a historical deployment. Full hardware-backed validation must
be performed after configuration; package checks alone do not establish it.
